# Changelog

All notable changes to `nish` are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow
[Semantic Versioning](https://semver.org/).

A section is written **when a release is cut**, not as development goes along:
the release commit fills in `## [<version>] - <date>` immediately before the
tag, and `scripts/changelog-section.sh <version>` turns that section into the
GitHub release notes. The procedure is in
[docs/wp12-release.md](docs/wp12-release.md). Between releases this file is
empty, and the account of what changed is the git log and the `docs/wp*.md`
design notes.
