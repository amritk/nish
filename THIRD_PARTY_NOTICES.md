# Third-party notices

This repository's [`LICENSE`](LICENSE) covers the code written for it. It does
not cover the files below, which are copied, ported or adapted from code
written elsewhere. Each keeps its upstream copyright notice and licence: the
file carries a header naming them, and the licence text is in the repository
beside it. [`.claude/licensing.md`](.claude/licensing.md) is the rule a new copy
follows, and `node tests/run.js third-party-licence` checks this file against
the tree.

## What the npm package ships

Four of these files ship. The first is `runtime/runtime.c`, whose shortest round-trip
formatter is adapted from Ryu. The package carries `runtime/LICENSE-ryu` beside
it, because `package.json`'s `files` names the whole `runtime/` directory, and
the release tarball and the platform packages copy that directory too. Ryu is
offered under Apache-2.0 or the Boost Software License 1.0, and this repository
takes the Boost licence. It asks for the notice only in copies of the source:
copies and derivative works "solely in the form of machine-executable object
code generated by a source language processor" are exempt. So the `nish`
binary, and every program `nish --link` builds, needs no notice of its own.

The second is `std/crypto/aes.ts`, whose `ghashMul32` (the 32-bit carry-less
product under GHASH) is adapted from BearSSL. The package carries
`std/crypto/LICENSE-bearssl` beside it, because `package.json`'s `files` names
the whole `std/` directory. BearSSL is under the MIT licence, which asks for
the notice in "all copies or substantial portions of the Software" and, unlike
the Boost licence, makes no exception for object code: a program built with
`nish/crypto/aes` and distributed carries BearSSL's notice with it.

The third is `std/crypto/p256.ts`, whose field and scalar arithmetic is ported
from fiat-crypto. The package carries `std/crypto/LICENSE-fiat-crypto` beside
it, for the same reason. fiat-crypto is offered under MIT, Apache-2.0 or
BSD-1-Clause, and this repository takes MIT, the one of the three on
[`.claude/licensing.md`](.claude/licensing.md)'s list. As with BearSSL, the MIT
licence makes no exception for object code: a program built with
`nish/crypto/p256` and distributed carries fiat-crypto's notice with it. The
same file's inversion of the signing nonce is ported from libsecp256k1, under
MIT too, so the package carries `std/crypto/LICENSE-libsecp256k1` beside it as
well, and such a program carries libsecp256k1's notice beside fiat-crypto's.

The fourth is `std/math.ts`, whose `Math.tan`, `Math.atan2` and `Math.hypot`
are ported from fdlibm, as FreeBSD's msun carries it. The package carries
`std/LICENSE-fdlibm` beside it, for the same reason. fdlibm's licence grants
use, copying and distribution "provided that this notice is preserved", which
the file's header does; it asks nothing of object code, so a program calling
those functions needs no notice of its own.

Nothing else here ships. `package.json`'s `files` names neither `bench/`,
`tests/`, `examples/` nor `docs/cookbook/`.

## Public-domain algorithms

These are named here so that nobody has to audit them again. They need no
notice, and each is marked public domain where its constants appear:

- FNV-1a (`src/map.ts`, `src/emit-map.ts`, `std/collections.ts`).
- MurmurHash3's `fmix32` and `fmix64` finalisers (`src/emit-map.ts`,
  `std/collections.ts`, and `fmix32` in `std/random.ts`).
- xorshift64* in `nish_random` (`runtime/runtime.c`).
- dudect's cropping schedule, its 100 percentiles and the 10,000-measurement
  gate on its second-order test (`tests/ct-timing/dudect.c`), from
  `src/dudect.h` in oreparaz/dudect, which is public domain under the
  Unlicense.
