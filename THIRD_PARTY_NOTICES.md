# Third-party notices

This repository's [`LICENSE`](LICENSE) covers the code written for it. It does
not cover the files below, which are copied, ported or adapted from code
written elsewhere. Each keeps its upstream copyright notice and licence: the
file carries a header naming them, and the licence text is in the repository
beside it. [`.claude/licensing.md`](.claude/licensing.md) is the rule a new copy
follows, and `node tests/run.js third-party-licence` checks this file against
the tree.

## What the npm package ships

One of these files ships: `runtime/runtime.c`, whose shortest round-trip
formatter is adapted from Ryu. The package carries `runtime/LICENSE-ryu` beside
it, because `package.json`'s `files` names the whole `runtime/` directory, and
the release tarball and the platform packages copy that directory too. Ryu is
offered under Apache-2.0 or the Boost Software License 1.0, and this repository
takes the Boost licence. It asks for the notice only in copies of the source:
copies and derivative works "solely in the form of machine-executable object
code generated by a source language processor" are exempt. So the `nish`
binary, and every program `nish --link` builds, needs no notice of its own.

Nothing else here ships. `package.json`'s `files` names neither `bench/`,
`tests/`, `examples/` nor `docs/cookbook/`.

## Public-domain algorithms

These are named here so that nobody has to audit them again. They need no
notice, and each is marked public domain where its constants appear:

- FNV-1a (`self/map.ts`, `self/emit_map.ts`, `std/collections.ts`).
- MurmurHash3's `fmix32` and `fmix64` finalisers (`self/emit_map.ts`,
  `std/collections.ts`).
- xorshift64* in `nish_random` (`runtime/runtime.c`).
