# WP62: Nish classes from a JSON Schema

**State:** Proposed · **Open work:** [#1860](https://github.com/amritk/nish/issues/1860) · **Design note:** [`docs/wp62-json-schema-classes.md`](https://github.com/amritk/nish/blob/main/docs/wp62-json-schema-classes.md)

## Open work

Open stages are the sub-issues of [#1860](https://github.com/amritk/nish/issues/1860), one pull request each, specified in [`.claude/plans/wp62-json-schema-classes.plan.md`](https://github.com/amritk/nish/blob/main/.claude/plans/wp62-json-schema-classes.plan.md). What waits on a decision is labelled `needs-decision` there.

## Not planned

A runtime schema interpreter, untagged unions by trial decoding, string enums, leaving absent optional keys out of the encoding, one file per `$defs` entry, OpenAPI 3.0, servers or clients from OpenAPI paths, a schema fetched over the network.
