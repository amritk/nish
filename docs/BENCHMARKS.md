## Data parallelism (ms, min / median)

Each kernel is one Nish binary, run as the loop a program writes without `nish/threads` (`seq`) and as `parallelMapInto` (`par`) on all 4 logical cores; the speedup is the loop's minimum over the map's. Both runs print the same checksum. The kernels are in `bench/par_*.ts`, and wp29 §8a reads the numbers.

## Commands

Sources are copied to `build/bench/src/` (with the size substituted when `--n` is given) and built from the repository root:

### fib

```
nish build/bench/src/fib.ts --link build/bench/fib-nish --profile speed
nish build/bench/src/fib.ts --nsw --link build/bench/fib-nish-nsw --profile speed
nish build/bench/src/fib.ts --link build/bench/fib-nish-size --profile size
clang -O3 -s build/bench/src/fib.c -lm -o build/bench/fib-c
rustc -C opt-level=3 -C panic=abort -C codegen-units=1 -C strip=symbols build/bench/src/fib.rs -o build/bench/fib-rust
rustc -C opt-level=3 -C panic=abort -C codegen-units=1 -C strip=symbols -C target-cpu=native build/bench/src/fib.rs -o build/bench/fib-rust-native
go build -trimpath -ldflags=-s -w -o build/bench/fib-go build/bench/src/fib.go
```

Rust flags: `-C opt-level=3 -C panic=abort -C codegen-units=1 -C strip=symbols`, plus `-C target-cpu=native` for the native column. Go has no optimisation level to choose: `-trimpath` and `-ldflags=-s -w` only strip the binary. `nish --link` runs `scripts/build.sh --profile speed` (`clang -O3 -flto` with section GC and stripping; see the README) over the module and `runtime/runtime.c`.
