# Registry codes no program can provoke, one `CODE  reason` per line.
#
# `tests/diagnostic_coverage.js` requires every code in `self/codes.ts` to be
# either provoked by the corpus or named here, so a diagnostic cannot quietly
# arrive without a test. A code listed here that turns out to be reachable is a
# failure as well: the list may shrink, and it may not rot.
#
# An unreachable diagnostic is a finding about the compiler rather than a test
# nobody wrote, which is why each line says which kind it is. None of them is a
# bug in what the compiler *does*; between them they say that `RULE_COUNT` is
# about fifteen percent larger than the number of rules a user can actually be
# shown.
