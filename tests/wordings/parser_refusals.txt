# that owns the rule. stage1's parser turns down the syntax the language
# forbids by name — `a class member is a field, a method or a constructor,
# found `{`` — before Phase 0 or the checker can state the rule that stage0
# states. That is the declared parity class of
# `docs/wp19-stage0-retirement.md` §A3 (602 rows), and closing it in code is
# grammar for 45 constructs that never compile.
#
# The consequence for this corpus is exact and worth saying plainly: **these
# wordings do not survive R6.** They are stage0's, they are pinned here while
# stage0 lives, and on the day `src/` goes the sentences go with it — what the
# user will see instead is the syntax error stage1 already prints, which is
# pinned by `tests/self/reject_oracle.js`'s parser bucket.
#
