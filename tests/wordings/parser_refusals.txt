# Cases the self-hosted compiler's parser refuses before the rule is stated,
# one case name per line.
#
# `.claude/selfhost.md`: lex and parse what is written, refuse in the phase
# that owns the rule. When stage0 went at R6, stage1's parser still turned
# down 45 forbidden constructs by syntax error — the declared parity class of
# `docs/wp19-stage0-retirement.md` §A3 — before Phase 0 or the checker could
# state the rule stage0 had stated, so the code went with stage0 and this list
# named the programs whose wording nothing printed any more. Each case's
# `.err` pins what a user sees instead, the parser's first sentence, so a
# parser that rewords the refusal, or refuses somewhere else, fails here.
#
# `npm test` runs the coverage tool over stage1 with `--strict-refusals`, so a
# case listed here that stage1 starts answering the same way is a failure: the
# list shrinks as the parser learns a rule, and it cannot grow by accident.
#
# The member-header family (`x?: T`, `x!: T`, `static`) came off first, as
# flags the checker reads. WP33 R1 then made the parser read every form the
# language forbids, in six stages — statements, expressions, declarations,
# function and binding forms, class, interface and enum forms, and import and
# export forms — each parsed into the node it resembles and refused by the
# phase that owns its rule, the shape `src/nodes.ts` writes down; the last
# stage took the six import and export wordings off. What is left is two
# wordings no stage was given, each behind a parser sentence about a class:
# `nl2118_override_method`, whose `override` method the parser reads as a
# field with no type annotation before the checker can name the modifier, and
# `nl2137_implements_expression`, whose `implements` names a member access the
# class header does not read. Each comes off with the change that moves its
# rule.
#
# One warning from the member-header change, because this list is where somebody will next
# take a wording off it: a case here proves what its *code* reaches, and a code
# can word more than one rule. `nl2116_static_method` reaches the method
# sentence; the constructor's shares the code, so nothing in this directory
# could tell that a `static` constructor had stopped being refused at all. It
# had. `tests/cases/reject_cls_ctor_static` is what pins it now, and a
# `reject_*` case is the thing to write when a wording comes off this list.
nl2118_override_method
nl2137_implements_expression
