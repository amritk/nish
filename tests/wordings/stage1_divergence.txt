# Cases where the two compilers do not say the same thing, one `case  what
# stage1 does` per line. Nothing here is declared: these are open differences,
# found by writing this corpus and reported rather than fixed, because a
# diagnostic code is keyed on its message text and rewording one retires the
# code (stage0's `src/codes.ts`).
#
# They are all invisible to `tests/self/parity.js`, and for one reason: that
# mode runs the *corpus* through fourteen flag variations, and no corpus
# program is written this way. §A2 of `docs/wp19-stage0-retirement.md` makes
# exactly this point about the five differences its first run found — "every
# oracle compiles a program with the flags that program already carries" — and
# this is the same gap seen from the other side: a flag nobody varies is one
# thing a cross product cannot reach, and a *program* nobody wrote is another.
#
# Two kinds, and the second is the serious one:
#
#   - **a different sentence**: both compilers refuse the program, and stage0
#     states the rule the registry has a code for while stage1 states a more
#     general one (or one with no code at all). The pinned wording is stage0's.
#   - **stage1 compiles it**: stage0 refuses the program and stage1 emits IR.
#     A rule the language documents is not enforced by the compiler that is
#     going to survive, which is a checker gap rather than a wording one.
#
# `npm test` runs the coverage tool over stage1 with `--strict-refusals`, so a
# line here that stops being true fails the run and has to be deleted.

# The file is empty of cases: every line it opened with is gone, closed rather
# than declared. Among them: the clash wordings, `++` on a string,
# the void ternary, the two 2^53 literals, the three `for...of` head rules and
# `new C<T>()`. The last two went together (#320): a duplicate type parameter,
# which stage1 compiled and now refuses in the pass 1 sweep (NL2302,
# `tests/cases/reject_generic_duplicate_type_parameter*`), and the empty
# statement `;`, which stage1 refused with an uncoded sentence and now refuses
# with NL2260's (`tests/cases/reject_stmt_empty`). Each is the same sentence at
# the same column on both sides. The header stays, and the tool still reads the
# file, so the next difference somebody finds has a place to be written down.
