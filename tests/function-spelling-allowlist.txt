# Test files that may still hold a top-level `function` definition.
#
# WP22 spells every function in the test corpus as a const arrow. The
# `arrow-corpus` check in tests/run.js fails on a tests/**/*.ts file that holds
# a definition `node scripts/arrowify.mjs` would rewrite (or cannot parse) and
# is not listed here, and on a listed file that no longer holds one. Each line
# is a path, then `#` and the reason the file keeps its `function` spelling.
# Forms the codemod refuses by design (`declare function`, `async`,
# `function*`, `export default`, a bodiless signature ending in `;`) are not
# definitions here.
#
# This list covers files. A Nish program written as a string literal inside a
# tests/**/*.js harness is checked by `node scripts/inline-functions.mjs`
# instead, and keeps `function` only under a `// nish-function: <reason>`
# comment at the literal or its statement.

# rewrite would move a position something else pins: a `-g` golden's

# leaves this list only together with the regenerated golden or the doc edit
# (#1723).
